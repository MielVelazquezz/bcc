#### 8.1 Como criar um projeto com npm:
```bash
npm init -y
```
O arquivo package.json carrega todas as informações do projeto.

#### 8.2 Comando para ativar "scripts" de package
`` npm run <namescript>
Exemplo: Adicionar em "scripts" do projeto:
```js
"scripts":{
	...
	"start":"node [nome_arquivo].js"
}
```

``` bash
npm run start
```

#### 8.3 Comando para instalar módulos
```bash
npm install <nomeModulo>
```

Pacotes globais: pacotes de módulos que não ficam salvos na pasta node.modules do projeto. Eles ficam salvos no computador, podendo ser acessado por qualquer usuário via terminal. Para usar um pacote global deve-se adicionar ``-g``  no comando de instalar: 
``npm install -g <nomeModulo> 
Para baixar arquivos que estão no repositório do projeto:
``npm link <nomeModulo>

#### 8.4 Comando para remover módulo do projeto:
``npm uninstall <nomeModulo>
