É uma ferramenta de escrita de objetos em JS. Permite leitura leve e simplificada composto pela estrutura ``"chave" : "valor"``, chave -> propriedade (atributo) do objeto.

#### 9.1 Estrutura JSON
- Declaração entre chaves: {...}
- Atributos separados por vírgula
- Atributos com chave-valor: {"chave" : "valor"}
- Atributo pode ter mais de um valor (array): \[...]
- Pode existir:
	- Array de objetos: \[{...}, {...}, {...}]
	- Matriz (array de array): \[\[...], \[...], \[...]]
	- Matriz de Objeto: \[\[\[{...}, {...}, \[{...}]]]
#### 9.2 Tipos de atributos JSON
- Inteiro/int: (0, 1, 2, ...)
- Flutuante/float: (2.9, 3.7, ...)
- Texto/string: ("Olá")
- Lógico/boolean: (true, false)
- Lista/array: (\["verde"], \["preto"])
- Objeto/json: ({"nome" : "Miel"})
- Nulo: null

Exemplo JSON:
```json
{
	"loja":"Loja & Cia",
	"cliente":[
		{ "nome": "Ana Paula",
		  "telefone": "99999-9999",
		  "id_compras": [123,97,3]
			
		},
		{ "nome": "Maria Clara",
		  "telefone": "99888-8888",
		  "id_compras": [1, 32, 94]
		}
	],
	"cnpj": "66.667.798.0002-36",
	"endereco": null
}
```
