# Sistema de Agenda Telefônica (Node  
Monte um sistema para cadastro e busca de contatos de uma agenda telefônica. O sistema deve atender os códigos HTML dos Anexos 5, 6 e 7.
  
## Critérios

- [x] **a)** O sistema deve iniciar na página `agenda.html`
- [ ] **b)** Ao cadastrar um contato, adicionar ao array de objetos `contatos` o objeto com nome e telefone, no arquivo `contatos.json` dentro do diretório `Agenda` (se não existir, criar). Ao adicionar, o navegador permanece na página `agenda.html`
- [ ] **c)** Só criar o contato se o telefone for válido. A validação é feita por um módulo interno `validaTel`, que retorna `true` se o telefone tiver tamanho 11, senão `false`
- [ ] **d)** Se o telefone não for válido, exibir `erroCadastro.html` com status `400`
- [ ] **e)** A busca por todos os contatos direciona para `contatos.html` e exibe todos os contatos do `contatos.json`
- [ ] **f)** A busca por um contato específico direciona para `contatos.html` e exibe somente os contatos com o mesmo nome enviado por POST
