## 10.1 Chunk
Quando é usado um protocolo http, e os dados são transmitidos em um pacote fracionado (pedaços ou blocos) no Node chamamos de *chunk*-> pequeno fragmento de dados transmitidos quando um arquivo grande é particionado (geralmente em formato Buffer) para envio.

> [!important] Como capturar os pedaços (chunks) dos pacotes transmitidos?
> Com o método `on`

## 10.2 Método On
Método para escutar reagir a eventos de transmissão de pacotes (fracionados-chunk) no Node.js.
Eventos:
- **'``data``'** (chegada dos pedaços): é disparado todas as vezes que um usuário envia um dado (texto/imagem/arquivo...) muito grande e o Node.js divide em partes menores (chunks) para o servidor.
```js
req.on('data', (chunk)=>{ // pedaço do dado que acabou de chegar
	body.push(chunk) // armazena os "pedaços" em uma lista
})
```

- **'``end``'** (fim do evento): "avisa" que o cliente enviou TUDO e a tranmissão foi concluída.
```js
req.on('end', ()=>{
	const dadosCompletos = Buffer.concat(body).toString()
	resp.end('Dados Recebidos!')
})
```
Ele junta todos os pedaços (chunks) acumulados no evento 'data' e transforma de volta em um texto ou ``json`` legível, finalizando com processamento da requisição.
