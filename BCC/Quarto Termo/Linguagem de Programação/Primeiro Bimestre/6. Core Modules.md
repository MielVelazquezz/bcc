### 6.3 Modulo fs  
Modulo para manipular arquivos e diretorios.  
  
**Metodos:**  
- readFile   
- writeFile  
- appendFile  
- unlink  
- exists  
- mkdir  
  
### 6.4 Modulo Path  
Modulo que permite extrair diversas informacoes sobre os caminhos dos arquivos.  
  
**Metodos**:  
- dirname  
- basename  
- extname  
- Resolve (path completo ate o arquivo final)  
- join (forma path dinamico, com variaveis e valores fixos)
