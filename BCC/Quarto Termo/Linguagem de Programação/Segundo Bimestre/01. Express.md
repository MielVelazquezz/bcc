**O que é?** É um framework (módulo externo - npm) para back-end utilizado em Node.js
**Características:** Leve, performático, simples.
**Para que é usado?** Para criar APIs. Permite: criar rotas: renderizar HTML, conectar com banco de dados.

## 1.1 Rotas
São URLs que acessamos -> \~={orange}www.meusite.com=~ ~={blue}/produtos=~ 

~={orange}◉=~ Domínio
~={blue}◉=~ Rotas -> Atrelada a uma funcionalidade do sistema -> ponte entre o usuário => lógica de aplicação

## 1.2 Setup (configuração) simples do Express
1) Importar e invocar (chamar) o módulo
2) Definir porta base da aplicação
3) Criar rota (URL) para ser acessada
4) Escutar a porta da app com listen

## 1.3 Método GET
```js
const app = express();
app.get('/', (req, resp)={
	...
})

/*
app -> variável que executa o express
get -> método HTTP
'/' -> URL que o usuário irá acessar
req -> dado que vem do usuário
resp -> resposta para o usuário
*/
```

## 1.4 Renderização HTML com Express
- Método **sendFile**: envia HTML como resposta passando o caminho relativo. Permite que o arquivo seja renderizado no navegador: 
```js
resp.sendfile(`${basePath}/index.html`);
```

- Método **path**: acessa o arquivo pelo diretório base:
```JS
const basePath = path.join(__dirname, 'diretorio')

/* 
__dirname -> diretorio atual que estou no momento
*/
```

## 1.5 Middleware
São códigos que podem ser executados no meio/entre uma ação e outra.
Exemplo: Verificar se o usuário está logado. Se o usuário estiver logado ele abre a página para acesso, caso contrário, notifica que é necessário logar.
- Método: ``use`` -> toda requisição se for enviada pela aplicação ele irá ativar o middleware:
```js
app.use(checkAuth)
const checkAuth = function(req, resp, next){
	req.authStatus = true
	
	if(req.authStatus) console.log('Logado')
	else console.log('É necessário logar')
		
	next()    
}  
```

## 1.6 Parâmetro URL
- Permitir acessar parâmetros da URL por meio de uma requisição req.params.\<nome>/usuarios/:nome

## 1.7 Método POST
- Pode ser enviado via form
- É necessário colocar o middleware `express.json` para ler os dados do body
- É necessário criar rota com método POST

## 1.8 Módulo de Rotas_Router
- Utilizado quando a aplicação cresce muito, permitindo várias rotas em um módulo, deixando o código mais organizado.
- É necessário (ideal) criar uma pasta com o arquivo das rotas -> router -> mapRouter.js
- Utiliza o método ``Router`` do express: `const rota = express.Router()`
- É necessário importar e exportar: mapRouter.js -> module.exports = rota; index.js -> `const rotas = require('./router')`

## 1.9 Express + CSS
- Utiliza middleware para inserir CSS nas páginas de arquivos estáticos.
- Método: express.static
- Cria um diretório base (public) para adicionar o arquivo CSS
- Pelo HTML será possível acessar o caminho relativo do css
-> Página 404 - não encontrada
- Criar um novo middleware abaixo de TODAS as rotas, assim ele tenta todas as possíveis rotas, caso nenhuma rota for atendida, então responde com 404.

## 02. [[02. Mongo DB|Mongo DB]]
Banco de dados não relacional (NoSQL) -> não é obrigatório existir relacionamentos entre chaves.
- BD focado em Documentos - documents -> objetosJS(json)
- Não utiliza queries => usa métodos de classes
- Não existe Tabelas => existe **collections** (não é necessário definir a estrutura)

**Características**
1) BD orientado a documentos
2) Dados salvos em estrutura BSON (similar ao json)
3) Frequentemente utilizado em Node.js

## 2.1 Principais Entidades/Elementos
- **Database**: local em que ficam as collections e os dados.
- **Collections**: como se fosse =m as "tabelas" local em que são inseridos os dados.

> [!NOTE] Sobre as Collections
> Podem ser criados livremente a qualquer momento, não precisa de "colunas" fixas
- **Documents**: dados.

## 2.2 Tipos de dados do MongoDB
BSON -> variação do JSON com mais recursos.
```BSON
forma:{
	chave1: "valor",
	chave2: 1
},
```

## 2.3 Primeiros Passos - MongoDB
1. Criar um Banco de Dados
2. Criar uma collection
3. Inserir e resgatar dados (métodos-find)

## 2.4 Mongoose
É um Object Data Mapping (ODM) - Mapeamento de dados para Objetos - mais usado no MongoDB.
- Deixa mais ágil o processo de trabalho
- Similar ao SQL -> Define-se o Model com dados e tipos
- Módulo
``` shell
npm install mongoose 
```
