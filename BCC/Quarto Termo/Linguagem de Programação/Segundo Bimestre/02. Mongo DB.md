Linguagem de query
```js
$eq // igual que
$ne // nao existe
$in // procura se existe entre o conjunto
$lt // menor que
$gt // maior que
$lte // menor igual que
$gte // maior igual que
```

**Exemplo:**
```js
{'data' : {'$lt':hoje}}
```

## Arquitetura do projeto em 3 camadas - MVC (Model, View e Controller)

#### Back-end:
- **Model**: Camada responsável de guardar os dados que serão armazenados no BD.
- **Controller**: Camada com a regra de negócio da aplicação, terá acesso ao BD para buscar as informações.

#### Front-end:
- **View**: Camada responsável pela interface, telas, front-end.

Os arquivos da aplicação serão armazenados na pasta src (source-font) -> tudo que ficará fora é do Node.js
