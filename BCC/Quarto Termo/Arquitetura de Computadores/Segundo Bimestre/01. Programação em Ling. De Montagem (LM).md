O processador acadêmico que será utilizado como base para o desenvolvimento de programas LM possui as seguintes características:
- Acesso a uma RAM com 256 posições de 12 bits (~={blue}256x12=~).
- Há registradores de 1, 4, 8 ou 12 bits.
- Não há sistemas de entrada e saída (o software não interage com o mundo externo -> sem teclado, monitor, arquivos, ...).
- Os dados a serem manipulados manipulados pelo programa devem ser inseridos pelo programador na RAM.
- Não há separação na memória RAM entre área de dados e área de programas. O controle dessas áreas é responsabilidade do programador.
- Todo programa deve ter sua 1a linha de execução colocada na posição 0 (zero) de memória.

**IP** (8 bits): Contém o endereço da próxima instrução.
**MAR** (8 bits): Reg. endereço de memória.
**GPR** (12 bits): Reg. geral de "entrada" e "saída" do processador
**OPR** (4 bits): Armazena o opcode da instrução -> operade resister
**ULA**: Somador + ACC (12 bits) + FLAG (1 bit)

## Ciclo de Busca:

> [!important]
> IP -> MAR
> M -> GPR
> IP+1 -> IP
> GPR(OP) -> OPR
