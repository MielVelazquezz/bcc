Exemplo:
- **Caso de uso:** Montar treino.
- **Atores:** Personal.
- **Breve Descrição** (3 a 4 linhas): O personal informa o aluno -> objetivo do treino e exercícios. O sistema valida os dados e finaliza o caso de uso.
- **Pré-condições** (pré-requisitos): Aluno cadastrado e matriculado.
- **Pós-condições** (garantias de sucesso): treino definido.
- **Requisitos Especiais** (Lista de funções -> atributos e detalhes): Transação em Banco de Dados


| Fluxo Normal                                                                                       | Fluxo Alternativo                                                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Ator informa dados do aluno e objetivo do treino<br>   a) CPF                                   | 2.1 - Aluno inexistente<br>   a) Sistema exibe mensagem de aluno inexistente e finaliza o caso de uso<br>   <br>2.2 - Aluno sem matrícula<br>   a) Sistema emite mensagem de alunos sem matrícula e redireciona para o caso de uso "Efetuar matrícula", e retorna para o passo 3 do ***Fluxo Normal.*** |
| 2. Sistema valida dados do aluno e lista os grupos musculares                                      |                                                                                                                                                                                                                                                                                                         |
| 3. Ator **informa** o grupo muscular desejado                                                      |                                                                                                                                                                                                                                                                                                         |
| 4. Sistema exibe exercícios do grupo muscular                                                      |                                                                                                                                                                                                                                                                                                         |
| 5. Ator informa o exercício, série, repetições, dia de treino e carga                              |                                                                                                                                                                                                                                                                                                         |
| 6. Sistema valida os dados, insere o item no treino e repete passos 3 ao 6 até que indique término |                                                                                                                                                                                                                                                                                                         |
| 7. Ator confirmar o treino                                                                         |                                                                                                                                                                                                                                                                                                         |
| 8. Sistema registra o treino e finaliza o caso de uso                                              |                                                                                                                                                                                                                                                                                                         |
