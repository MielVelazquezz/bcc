Matriz a qual a grande maioria dos elementos possui valor padrão (0 por exemplo) ou são nulos/faltantes.

Seria um desperdício gastar uma matriz de $m x n$ posições de memória sabendo uma pequena parcela dos elementos tem valor diferente de 0.
Para evitar desperdício de memória (e eventualmente de processamento) criamos uma estrutura para gerenciar matrizes esparsas -> só serão alocados elementos diferentes de 0 e alguma estrutura adicional de controle.

### Implementação
Cada linha da nossa matriz será representada por uma lista ligada que só conterá elementos com valores diferentes de 0 -> arranjo de listas ligadas.

```C
#define nl 5 
#define nc 6

struct matrizEsp{
	int lin, col, valor; 
	struct matrizEsp *pc, *pl; 
}; typedef struct matrizEsp MatEsp
```
