 Uma árvore é uma forma de guardar dados em níveis, como uma árvore genealógica ou as pastas do computador. Uma lista guarda tudo em fila (um depois do outro). A árvore guarda com ramificações -> um elemento poder ter vários "filhos".
 Serve para resolver problemas na computação como por exemplo: expressões matemáticas, pastas e arquivos, compressão de música e foto.

#### Ancestral e Descendente
- Se **x** está dentro da subárvore de **v**, então **x é descendente de v** e **v é ancestral de x** (como avô e neto).
- Se x e v são nós **diferentes**, dizemos "próprio": x é descendente **próprio** de v.

#### Folha e nó interior
- **Folha:** nó **sem filhos** (grau de saída 0). É a ponta da árvore.
- **Nó interior:** nó **com filhos** (grau de saída diferente de 0).

#### Nível e altura
- **Nível (profundidade):** quantos nós existem no caminho da raiz até ele. A **raiz tem nível 1**.
- **Altura** de um nó: quantos nós existem no maior caminho dele até uma folha lá embaixo. **Folha tem altura 1**.

#### Árvore cheia
Todo nó tem o **máximo de filhos**, menos as folhas, e **todas as folhas ficam no mesmo nível**. Não falta nenhum nó.

**Árvore cheia de grau 2 guardada em vetor:** os nós são guardados **nível por nível**, da esquerda para a direita.

## Árvores Binárias
Uma árvore binária é uma estrutura de dados não linear onde cada elemento (**nó**) possui no máximo dois nós filhos, conhecidos como filho à esquerda e filho à direita.
Ou é vazia, ou tem uma raiz com duas subárvores (esquerda e direita), e cada uma delas também é uma árvore binária.

```C
struct tree{
	int info;
	struct tree *esq, *dir;
};
typedef struct tree Tree;
```

```C
Tree *CriaNo(int info){
	Tree *no = (Tree *)malloc(sizeof(Tree));
	
	no->info=info;
	no->esq=no->dir=NULL;
	
	return no;
}
```

```C
void LocalizaNo(Tree *raiz, int info, tree **aux){
	if(raiz!=NULL){
		if(info==raiz->info){
			*aux=raiz;
		}
		else{
			LocalizaNo(raiz->esq, info, &*aux); // ñ precisa de '()' pq ñ tem '->'
			
			if(*aux==NULL) // se ñ achou indo para a esq vai pela dir
				LocalizaNo(raiz->dir, info &*aux);
		}
	}
}
```

```C
void Insere(Tree **raiz, int info, int info_pai, char lado){
	Tree *pai=NULL;
	
	if(*raiz==NULL) 
		*raiz=CriaNo(info);
	else{
		LocalizaNo(*raiz, info_pai, &pai);
		if(pai!=NULL){
			if(lado=='e' && pai->esq==NULL){
				pai->esq=CriaNo(info);
			}
			else if(lado=='d' && pai->dir==NULL)
				pai->dir=CriaNo(info);
		}
	}
}
```

```C
void InsereR(Tree **raiz, int info){
	
	if(*raiz==NULL){
		*raiz=CriaNo(info);
		return;
	}
	
	if(info < (*raiz)->info) 
		Insere(&(*raiz)->esq, info);
		
	else if(info > (*raiz)->info) 
		Insere(&(*raiz)->dir, info);
	
}
```

## Árvore Binária de Busca (ABB)

```C
void InsereABB(Tree **raiz, int info){
	Tree *aux, *ant;
	if(*raiz==NULL) *raiz = CriaNo(info);
	else{
		aux=*raiz;
		while(aux!=NULL){
			ant = aux;
			if(info<aux->info) aux=aux->esq
			else aux=aux->dir;
		}
		if(info < ant->info)
			ant->esq=CriaNo(info);
		else 
			ant->dir=CriaNo(info);
		
	}
}
```

```C
void InsereABB(Tree **raiz, info){
	Tree *aux;
	char flag=0;
	if(*raiz==NULL) *raiz=CriaNo(info);
	else{
		aux=*raiz;
		while(!flag){
			if(info < aux->info){
				if(aux->esq==NULL) {
					aux->esq=CriaNo(info);
					flag=1;
				}
				else aux=aux->esq;
			}
			else{
				if(aux->dir==NULL) {
					aux->dir=CriaNo(info);
					flag=1;
				}
				else aux=aux->dir;
				
			}
		}
	}

}
```

```C
Tree *BuscaABB(Tree *raiz, int info){
```

```C
void ExcluirABB(Tree **raiz, Tree *e, Tree *pai, char lado){
	if(e->esq==NULL&&e->dir==NULL){ // e é folha
		if(e!=pai){
			if(e->info>pai->info){
				pai->dir=NULL;
			}
			else{
				pai->esq=NULL;
			}
		}
		else{
			*raiz=NULL;
		}
	}
	else if(e->esq==NULL||e->dir==NULL){ // e tem 1 filho
		if(e!=pai){
			if(e->info>pai->info){
				pai->dir = e->dir;
			}
			else{
				pai->dir = e->esq;
			}
		}
		else{
			if(e->dir!=NULL){
				*raiz=e->dir;
			}
			else{
				*raiz=e->esq;
			}
		}
	}

		}

			}

			ExcluirABB(&*raiz, sub, paisub, lado);

		}
	}
```

## Balanceamento de ABB
Árvore binária perfeitamente balanceada

Supondo que tenhamos uma árvore assim:

![[Pasted image 20261022134943.png|center]]

![[Pasted image 20261022135319.png|center]]

FB = qtdDireita - qtdEsquerda
FB = {-1, 0, 1}

```C
void BalanceamentoABB(Tree **raiz){
	
	int qtdD = qtdE = 0;
	quantNo(no->dir, &qtdD);
	quantNo(no->esq, &qtdE);
	int FB = qtdD - qtdE;
	Fila *f; init(&f); 
	
	enqueue(&f, *raiz);
	
	while(!isEmpty(f)){
		dequeue(&f, &no);
		
		do{
			if(FB<-1||FB>1){ // abs(FB)>1
				Tree *aux = no->info;
				if(no->esq==NULL){
					no=no->dir;
				}
				else if(no->dir==NULL){
					no=no->esq;
				}
				Busca(*raiz, aux, &e, &pai);
				if(FB>0){
					Exclusao(&*raiz, e, pai, 'd');
				}
				else {
					Exclusao(&*raiz, e, pai, 'e');
				}
				InsereABB(&*raiz, aux);
			}
		}while(FB<-1||FB>1);
		
		if(no->esq!=NULL){
			enqueue(&f, no->esq);
		}
		if(no->dir!=NULL){
			enqueue(&f, no->dir);
		}
	} 
}	
```

## [[02. Árvore de Huffman| Árvores de Huffman]]
É um jeito de **compactar dados sem perder nada**. A ideia: o que **aparece mais vezes ganha um código binário curto**, e o que aparece pouco ganha um código maior. Assim o arquivo total fica menor.

**JPEG:** compacta imagem **perdendo um pouco de qualidade**. A perda acontece na **quantização**. O Huffman entra depois, só para compactar o resultado.

- `.jpg` -> imagem com perdas
- `.raw` -> imagem crua, sem compressão
