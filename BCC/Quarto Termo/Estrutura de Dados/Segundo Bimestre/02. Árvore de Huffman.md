Uma árvore de Huffman é uma árvore estritamente binária usada para compressão (ação de apertar, reduzir o volume ou compactar algo) de arquivos, visando reduzir o espaço necessário para armazená-los em disco ou o tempo necessário para transmiti-los por um canal de comunicação.

Há duas formas de comprimir o arquivo, sendo elas:
- **Tamanho Fixo** (CTF): Todos os caracteres do alfabeto recebem códigos com a mesma quantidade exata de bits.
- **Tamanho Variável** (CTV): As letras que menos aparecem ganham mais bits e os que mais aparecem ganham menos bits.

Para melhor entendimento usarei como exemplo a frase "Abracadabra!":

"Abracadabra!" contém 12 letras no total, sendo: 1 "A"; 2 "b"; 2 "r"; 4 "a"; 1 "c"; 1 "d" e 1 "!", ou seja, 7 caracteres distintos, então 3 bits (111 -> $\lceil \lg 7 \rceil$).

Em CTF ficaria: 

| Caractere | CTF |
| --------- | --- |
| !         | 000 |
| A         | 001 |
| c         | 010 |
| d         | 011 |
| b         | 100 |
| r         | 101 |
| a         | 110 |
Ou seja, 12 (n° total de letras) * 3 (qtd. bits) = 36 bits, isso é 37,5% do tamanho que tinha antes (12 * 8 (ASCII) = 96).

Em CTV ficaria:

| Caractere | Frequência | CTV  |
| --------- | ---------- | ---- |
| !         | 1          | 0000 |
| A         | 1          | 0001 |
| c         | 1          | 0010 |
| d         | 1          | 0011 |
| b         | 2          | 010  |
| r         | 2          | 011  |
| a         | 4          | 1    |
 Com esse novo código, o arquivo comprimido passa a ter (fórmula = frequência * qtd. bits): 1 * 4 + 1 * 4 + 1 * 4 + 1 * 4 + 2 * 3 + 2 * 3 + 4 * 1 = 32 bits -> isso é 33.3% do tamanho que ele tinha antes. 
 
Então uma árvore de Huffman é uma estrutura que representa um código de tamanho variável, que minimiza o número de bits necessários para representar um arquivo. Diferentemente do código ASCII, que é padrão, o código de Huffman varia em função do arquivo que é comprimido (e, portanto, deve ser criado especificamente para cada arquivo).
Além disso o código de um caractere nunca é o começo do código de outro, e é isso que garante a descompressão sem ambiguidade porquê na árvore, o código de cada caractere é o caminho da raiz até a folha: 0 para a esquerda e 1 para a direita.

### 01. freq():

**O que faz:** devolve um vetor `f` onde `f['a']` é quantas vezes o `a` apareceu.

**Porquê faz:** o código de cada letra depende de quanto ela aparece. Sem a contagem, não dá para saber quem merece código curto/longo (qtd. bits).


```C
int *freq(char *s){
	static int f[256];
	for(int i=0; i<256; i++) f[i] = 0;
	for (int i=0; s[i]; i++) f[s[i]]++;
	return f;
}
```

**Passo a passo:**
1. O vetor f tem **256 posições**, uma para cada caractere ASCII.
2. O primeiro `for` zera tudo.
3. O segundo `for` lê o texto. Para cada letra, soma 1 na posição dela. A letra é usada **como número da posição**: `f['a']++` soma 1 na posição do `a`.

> [!important] Detalhando:
> A função freq() usa um vetor estático f (isto é, que permanece na memória quando a execução da função termina), cujas posições são todas iniciadas com 0. Conforme a cadeia s é percorrida, para cada caractere s \[i], o contador correspondente f \[s\[i]] é incrementado. Assim, no fim do percurso, o vetor f indica a frequência de cada caractere ASCII em s. 

Por exemplo, para s = "A" e i = 0, a instrução f\[s\[i]]++ equivale a f\['A']++ (isto é, conta uma ocorrência de 'A').

### 03. insf():

Uma floresta será representada por um vetor F com m árvores de Huffman, em ordem decrescente de peso. Para garantir a ordenação da floresta, dadas uma árvore A e uma floresta F com m árvores, essa função **insere árvore A em F, em ordem decrescente de peso, e incrementa m**. O parâmetro m, que indica o tamanho da floresta, é passado por referência.

```C
void insf(Arvh A, Arvh F[], int *m){
	int i= *m; 
	
	while(i>O && F[i-1]->freq < A->freq){
		F[i] = F[i-1]; 
		i--;
	}  
	
	F[i] = A; 
	(*m)++;
}	
```

**Porquê faz:** com a lista sempre ordenada, a **menor árvore fica sempre no final**. Assim, para pegar a menor, basta tirar a última (é o que `remf()` faz).

---
### 04. remf():

Como uma floresta é um vetor de árvores em ordem decrescente de peso, para remover uma árvore de peso mínimo da floresta, basta remover a última árvore do vetor. Dada uma floresta F com m árvores, a função definida a seguir decrementa m e devolve a última árvore de F como resposta.

**Resumindo:** A função diminui `m` em 1 e devolve a **última** árvore da lista (a de menor peso).

```C
Arvh remf(Arvh F[], int *m){
	if( *m == 0 ) abort(); 
	return F[--(*m)];
}
```

### 05. huffman():

A função huffman(), definida a seguir, cria uma árvore de Huffman correspondente a uma cadeia de caracteres s, que é dada como parâmetro.

**Resumindo:** recebe o texto e devolve a árvore de Huffman pronta.

```C
Arvh huffman(char *s){ 
	Arvh F[256]; 
	int m = 0; 
	int *f = freq(s); 
	
	for (int c=0; c<256; c++) 
		if(f[c]>0 ) 
			insf(arvh(c,f[c],NULL, NULL),F, &m);
	
	while(m>1){ 
		Arvh d = remf (F, &m);
		Arvh e = remf(F,&m); 
		insf (arvh(e,'-',e->freq+d->freq,d), F, &m); 
	}
	return F[0];
```

A função huffman() chama a função freq() para obter o vetor f, com as frequências dos caracteres ASCII em s. Em seguida, para cada caractere e que ocorre em s (isto é, tal que f \[c]>0), ela cria uma folha contendo c e f\[c] e insere essa folha na floresta F. A partir daí, enquanto houver mais que uma árvore em F, ela remove de F duas árvores de pesos mínimos, cria um nó pai para elas, contendo a soma de seus pesos, e insere esse nó na floresta (note que, para nós que não são folhas, o valor do campo caractere é irrelevante). No final, a árvore que sobra na floresta é a árvore de Huffman devolvida como resposta.

### 06. exibeh():

Esta função usa um percurso em-ordem para visitar os nós da árvore e uma variável estática n para indicar o nível de cada nó na árvore. No início de cada chamada, o valor de n é incrementado e, no final, ele é decrementado. Então, para cada nó visitado, o valor n pode ser usado para endentar a exibição do nó (isto é, para produzir um espaçamento de 5 colunas por nível, antes de exibir os dados guardados no nó).

```C
void exibeh(Arvh A){
	static int n =-1; 
	
	if( A != NULL){
		n++; 
		exibeh (A->dir);
		
		for (int i=0; i<5*n; i++) 
			printf(" "); 
			
		printf("(%c, %d)\n",A->caractere,A->freq); 
		exibeh (A->esq);
		n--;
	}
}
```

### 07. codigo():

**O que faz:** percorre a árvore em-ordem anotando o caminho e, ao chegar numa folha, mostra a letra e o caminho.

```C
void codigo(Arvh A){ 
	static char d[256], t =-1; 
	
	if( A == NULL) 
		return; 
	
	if(A->esq == NULL && A->dir == NULL)
		printf("%c: %.*s\n",A->caractere,t+1,d); 
	else{ 
		t++; 
		d[t] = '0'; codigo (A->esq); 
		d[t] = '1'; codigo (A->dir); 
		t--;
	}
}	
```

Na função `codigo()`, o vetor estático d guarda uma cadeia de dígitos, criada conforme as chamadas recursivas são feitas: antes de uma chamada à esquerda, d é estendido com o dígito '0' e, antes de uma chamada à direita, d é estendido com o dígito '1'. Note que o vetor d funciona como uma pilha com topo t (isto é, que indica a posição do último dígito inserido em d). Então, quando uma folha é alcançada durante o percurso da árvore, o valor de t é usado em printf() para truncar a exibição da cadeia d (pois d não tem '\0'). O truncamento de cadeia é feito com o formato "*.*s", que tem como parâmetros o tamanho da cadeia a ser exibida (isto é, t+1) e um ponteiro para cadeia (isto é, d).

Por exemplo, a chamada `codigo(huffman("Abracadabra!"))` produz a saída:

### 09. comprimir():

**O que faz:** para cada letra do texto, mostra o código dela.

```C
void comprimir(char *s, Arvh A){
	char *T[256];
	for(int c=0; c<256; c++) 
		T[c] = NULL;
		
	tabela(A, T);
	
	for(int i=0; s[i]; i++) 
		printf("%s", T[s[i]]);
	
	for(int c=0; c<256; c++)
		free(T[c]);
}
```
**Como funciona**:
1. Cria a tabela `T` e coloca `NULL` em tudo (ninguém tem código ainda).
2. `tabela(A, T)` preenche com os códigos da árvore.
3. Para cada letra do texto, imprime o código dela (`T[s[i]]`).
4. Libera a memória das cópias com `free`.

Por exemplo, a chamada `comprimir("Abracadabra!", A)` produz a saída: 00110100111000010001101001110010

### 10. descomprimir():

**O que faz:** recebe a sequência de 0 e 1 e a árvore, e escreve o texto de volta.

```C
void descomprimir(char *d, Arvh A){
	if( A == NULL ) return;
	Arvh n = A;
	for(int i=0; d[i]; i++){
		n = (d[i]=='0') ? n->esq : n->dir;
		if( n->esq == NULL && n->dir == NULL ){
			printf("%c", n->caractere);
			n = A;
		}
	}
}
```

**Como funciona:**
1. Começa na **raiz** (`n = A`).
2. Lê um bit: `0` vai para a **esquerda**; `1` vai para a **direita**.
3. Chegou numa **folha** -> escreve a letra e **volta para a raiz**.
4. Repete até acabarem os bits.

Por exemplo, `descomprimir ("00110100111000010001101001110010", A)` gera a saída: Abracadabra!

**14.2** A *taxa de compressão* de uma árvore de Huffman `A`, criada a partir de uma cadeia `s`, é:

$$\gamma = \left(1 - \frac{T_H}{T_A}\right) \times 100\%$$

onde $T_H$ é o total de bits da cadeia comprimida e $T_A$ é o total de bits de `s` codificada em ASCII. Calcule a taxa de compressão de `"marmelada"` usando as duas árvores do exercício anterior.

$$\gamma = \left(1 - \frac{22}{9 \times8}\right) \times 100\%$$
(9 x 8 porque é o número de caracteres * 8 bits (ASCII))

$$\gamma = \left(1 - \frac{22}{72}\right) \times 100\% = 69,44..\% $$

Ou seja, o texto comprimido ficou 69,44% menor que o original

**14.3** A taxa de compressão também pode ser calculada usando apenas os dados da própria árvore `A`:

- $T_A$ é a frequência guardada na raiz multiplicada por 8, ou seja, `8 * A->freq`.
- $T_H$ é a soma, para cada folha, de (frequência da folha) × (comprimento do caminho da raiz até ela).

Exemplo com `"Abracadabra!"`: as folhas contribuem com 1×4, 1×4, 1×4, 1×4, 2×3, 2×3 e 4×1.

- **(a)** Crie a função `Th(A, c)`, que calcula $T_H$ para a árvore `A`. Ela deve ser chamada com `c = 0`, e a cada chamada recursiva `c` aumenta em 1, de modo que, ao chegar numa folha, `c` seja o comprimento do caminho percorrido. Estratégia recursiva: se `A` é folha, devolve `c * A->freq`; senão, devolve `Th(A->esq, c+1) + Th(A->dir, c+1)`.

```C
int Th(Arvh A, int c){
	if(A->esq == NULL && A->dir == NULL)
		return c * A->freq;
	
	return Th(A->esq, c+1) + Th(A->dir, c+1);	
}

```

- **(b)** Usando `Th()`, crie a função `taxa(A)`, que devolve a taxa de compressão obtida com a árvore `A`.

```C
double taxa(Arvh A){
	int tA = 8 * A->freq, tH = Th(A, 0);
	
	return (1.0 - (double)tA/tH)*100.0;
}
```

- **(c)** Crie um programa para testar `taxa()`. Por exemplo, `taxa(huffman("marmelada"))` deve devolver `69.4`.

```C
int main() {
   printf("%.1f\n", taxa(huffman("marmelada")));
   return 0;
}
```
