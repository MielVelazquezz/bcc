É uma árvore que quando insiro o elemento, se o elemento que insere a deixa desbalanceada, o algoritmo corrige, deixando a árvore balanceada.

o fator de balanceamento é dito pela **altura**: FB{-1, 0, 1}


### Tipo 1: (2)(1) ou (-2)(-1)

**Exemplo 1:** 

```C
void RotacaoEsq(Tree **p){
	Tree *q, *temp;
	q = (*p)->dir;
	temp = q->esq;
	
	q->esq = *p;
	(*p)->dir = temp;
	*p = q;
}
```

```C
void RotacaoDir(Tree **p){
	Tree *q, *temp;
	q = (*p)->esq;
	temp = q->dir;
	
	q->dir = *p;
	(*p)->esq = temp;
	*p = q;
}
```
