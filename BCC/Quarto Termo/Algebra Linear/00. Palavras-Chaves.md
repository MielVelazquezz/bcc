Este documento resume de forma simples os principais conceitos da Álgebra Linear explicados anteriormente, detalhando o que são e para que servem.

## 1. Sistemas Lineares

- **O que são:** um conjunto de duas ou mais equações com várias incógnitas que precisam ser resolvidas simultaneamente.
- **Exemplo básico:** descobrir o preço de uma coxinha e de um suco sabendo apenas o valor total de dois pedidos combinados de formas diferentes.
- **Pra que servem:** prever resultados quando muitas variáveis dependem umas das outras.
    - _Economia:_ equilibrar a oferta e a demanda de um mercado com centenas de produtos interdependentes.
    - _Engenharia de Trânsito:_ calcular o fluxo de carros em uma rede de avenidas para otimizar semáforos e evitar congestionamentos.

> [!note] Conexão É exatamente esse tipo de sistema que os métodos de [[01. Método de Gauss-Jordan|Gauss-Jordan]] e da [[02. Método da Matriz Inversa|Matriz Inversa]] resolvem — ambos representam o sistema como matriz para não precisar resolver por substituição, equação por equação.

## 2. Matrizes

- **O que são:** tabelas organizadas em linhas e colunas utilizadas para armazenar e organizar números.
- **Pra que servem:** guardar e processar grandes volumes de dados de forma compacta e estruturada.
    - _Imagens Digitais:_ cada foto na tela do seu celular é uma matriz, onde cada célula (pixel) guarda um número correspondente a uma cor específica.
    - _Física e Engenharia:_ armazenar dados de forças e tensões aplicadas em diferentes pontos da estrutura de uma ponte ou asa de avião.

> [!note] Conexão Um sistema linear vira, na prática, uma **matriz aumentada** (coeficientes | termos independentes) — é sobre essa matriz que rodam todas as operações do [[01. Método de Gauss-Jordan|Gauss-Jordan]].

## 3. Inversão de Matrizes

- **O que é:** o equivalente à divisão no mundo das matrizes. Na matemática comum, o inverso de 5 é 1/5, e 5 × 1/5 = 1. A matriz inversa (A⁻¹), quando multiplicada pela matriz original (A), resulta na Matriz Identidade (que funciona como o número 1 para matrizes).
- **Pra que serve:** "desfazer" uma alteração ou isolar uma incógnita, contornando o fato de que não existe divisão direta entre matrizes.
    - _Criptografia:_ uma mensagem é codificada ao ser multiplicada por uma matriz. Quem a recebe usa a matriz inversa para decodificar e ler o texto original.
    - _Gráficos de Jogos (Computação Gráfica):_ se uma matriz aplica uma transformação (como mover ou rotacionar um personagem), a matriz inversa calcula exatamente como reverter essa ação.

> [!note] Conexão Para matrizes 3×3 ou maiores, a forma mais comum de obter A⁻¹ é justamente via **escalonamento** — o mesmo processo do Gauss-Jordan, só que aplicado à matriz [A | I] até virar [I | A⁻¹]. Ver detalhes em [[02. Método da Matriz Inversa]].

## 4. Posto (Rank) de uma Matriz

- **O que é:** o número de linhas ou colunas que trazem informações realmente novas e independentes dentro da matriz. Linhas que são apenas cópias ou combinações de outras são consideradas redundantes.
- **Pra que serve:** indicador de consistência e quantidade de informação, revelando se um sistema possui solução e se ela é única.
    - _Sistemas de Equações:_ determina se os dados disponíveis são suficientes para encontrar uma resposta exata (solução única), se dão margem para infinitas respostas ou se são contraditórios (nenhuma solução).

> [!note] Conexão O posto não é só teoria — é o que se **observa na prática** ao rodar o Gauss-Jordan:
> 
> - nº de linhas não-nulas ao final do escalonamento = posto da matriz;
> - posto = nº de incógnitas → solução única;
> - linha `0 0 0 | k` com k ≠ 0 → sistema impossível;
> - linha de zeros sem contradição → infinitas soluções.
> 
> Ver o passo a passo completo em [[01. Método de Gauss-Jordan]].
