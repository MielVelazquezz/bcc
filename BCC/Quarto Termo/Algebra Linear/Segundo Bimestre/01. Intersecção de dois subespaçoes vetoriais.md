## Combinação Linear
É quando um vetor consegue ser obtido através de combinações de outros vetores.

1) Exercício: Escrever o vetor  $v= (-4, -18, 7)$ como combinação linear dos vetores $v1= (1, -3, 2)$ e $v2 = (2, 4, -1)$.
	
	$(-4, -18, 7) = a1(1, -3, 2) + a2(2, 4, -1)$
	$(-4, -18, 7) = (a1, -3a1, 2a1) + (2a2, 4a2, -a2)$
	$(-4, -18, 7) = (a1 + 2a2, -3a1 + 4a2, 2a1 - a2)$
	escalona
	$(-4, -18, 7) = 2(1, -3, 2) - 3(2, 4, -1)$

## Subespaços Gerados
**Span**{} -> conjunto de vetores recorrentes de combinações de vetores

Exemplo:
Quais são os vetores gerados por $v1=(1,1)$ e $v2=(2,2)$? 
Span{v1, v2} = a(1,1) + b(2,2) = (a+ 2b, a + 2b) => (x, x)

1) Exercício: Seja V= R³. Determine o subespaço gerado pelo vetor v=(1,2,3).
	(t, 2t, 3t)
	
2) Determine o conjunto gerado por cada par de vetores:
	a) v1 = (1,2,3), v2=(2, 4, 6) => (a+2b, 2a+4b, 3a + 6b)
	b) v1 = (1, 0, 1), v2=(0, 1, 1) => (a, b, a+b)
	
3) Verifique se o vetor (3, 4) pertence ao span de v1 = (1, 2) e v2=(2, 1)
