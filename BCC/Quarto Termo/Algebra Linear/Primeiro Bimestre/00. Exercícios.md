**4.** Somando a linha 1 com a linha 2 obtém-se exatamente a linha 3 do lado dos coeficientes (3, 0, 4); logo, para consistência, a soma dos termos independentes também deve bater: k = 2 + 5 = **7**. O foco aqui é o **tipo de enunciado** da Atividade Avaliativa 1: em vez de "faça Gauss", a prova pede para você **classificar, justificar, discutir, relacionar postos, estabelecer condições**. As questões abaixo foram escritas no mesmo estilo (inspiradas nos tipos de questão que aparecem em listas de universidades e sites, listados no final). Gabarito resumido logo depois.

## Palavra-chave → o que a prova espera

| Enunciado diz...                               | Você faz...                                                                              |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------- |
| "Classifique o sistema"                        | escalona, calcula p (posto da ampliada) e q (posto de A), compara com n → SPD / SPI / SI |
| "Indique postos e graus de liberdade"          | p, q e G = n − p                                                                         |
| "Discuta o sistema em função de k"             | descobre quando o determinante zera; testa esses valores separadamente no escalonamento  |
| "Determine a e b para que seja SPI (ou SI)"    | força a última linha do escalonamento: `0 0 0 \| 0` (SPI) ou `0 0 0 \| ≠0` (SI)          |

| "Conjunto solução"                             | escreva em função das variáveis livres: S = {(...) : z ∈ R}                              |
| "É subespaço?"                                 | (0,0,0) ∈ S? fechado na soma? fechado no escalar?                                        |

## Gabarito resumido

**1.** p = q = 3 < n = 6 → **SPI**; variáveis livres = 6 − 3 = **3**; G = **3**.

**2.** a) **F** (X = 0 sempre é solução, então p = q sempre). b) **V**. c) **V** (Rouché-Capelli: possível ⇔ p = q). d) **F** (posto ≤ m < n, então p = q < n → nunca SPD). e) **F** (pode ser possível, como o sistema da marcenaria, com equações redundantes).

**3.** A linha `0 0 0 | 5` é a equação 0 = 5, absurda → o posto da ampliada é maior que o de A (p > q) → **SI**.

**4.** Acrescentar a coluna de zeros não muda o posto → p = q sempre → nunca SI. Tem solução não trivial quando p = q < n (colunas sem pivô = variáveis livres).

**5.** det = a − 6. 
(i) **a ≠ 6** (qualquer b) → SPD. Com a = 6: 2ª linha vira 3·(1ª) nos coeficientes;
(ii) **a = 6 e b = 3** → SPI; 
(iii) **a = 6 e b ≠ 3** → SI.

**6.** Escalonando: L3 − L1 − L2 dá `0 0 k−5 | 0`. Se **k ≠ 5**: z = 0, y = 1, x = 1 → **SPD**, solução (1, 1, 0). Se **k = 5**: linha nula, p = q = 2 < 3 → **SPI**, G = 1, S = {(1 + z, 1 − 2z, z) : z ∈ R}. Não existe k que dê SI.

**7.** Coeficientes: linha 3 = linha 2 − linha 1. Escalonando, a linha nula fica `0 0 0 | b₃ − b₂ + b₁`. Condição: **b₃ = b₂ − b₁**.

**8.** Linha 3 = linha 2 − linha 1 → p = q = 2 < 3 → **SPI**, G = 1. Resolvendo: x = −z/3, y = 5z/3. Com z = 3t: **S = {t·(−1, 5, 3) : t ∈ R}**.

**9.** det = 4 − k. Solução não trivial quando det = 0 → **k = 4** (nesse caso p = q = 2 < 3, G = 1). Para k ≠ 4, só a solução trivial (SPD).

**10.** a) **V**. b) **V**. c) **F** (SPI em R² = retas coincidentes; concorrentes é SPD). d) **V**. e) **V**.

**11.** Sistema: 2x + 4y = 26 · 3x + y = 14 · x + y = 8. Escalonando, uma equação é redundante: p = q = 2 = n → **SPD**, **x = 3 e y = 5**. (Confere: 6 + 20 = 26; 9 + 5 = 14; 3 + 5 = 8.)

**12.** A = \[\[1,1,0],\[0,1,1],\[1,0,1]], 
det A = 2 ≠ 0 → invertível. 
A⁻¹ = ½·\[\[1,−1,1],\[1,1,−1],\[−1,1,1]]. X = A⁻¹·(5, 7, 6) = **(2, 3, 4)**.

**13.** a) **Sim** (reta pela origem).
b) **Não** — (0,0,0) não satisfaz x + y + z = 1. 
c) **Não** — (1,0) e (0,1) estão em W, mas (1,0) + (0,1) = (1,1) tem produto 1 ≠ 0 (não fechado na soma).
d) **Não** — (1,1,0) ∈ W, mas 2·(1,1,0) = (2,2,0) tem y = 2 ≠ 4 = x² (não fechado no escalar).
e) **Sim** (soma e múltiplo escalar de triangulares superiores continuam triangulares superiores).
f) **Não** — \[\[1,0],\[0,0]] e \[\[0,0],\[0,1]] têm det 0, mas a soma é a identidade, com det 1.

**14.** **Não.** O vetor nulo não é solução, pois A·0 = 0 ≠ B. Sem o vetor nulo, não é subespaço. (Só o caso homogêneo é subespaço.)

**15.** A origem {(0,0,0)}, as **retas** que passam pela origem, os **planos** que passam pela origem e o próprio R³.

**16.** dim S = n − p = 12 − p, e p ≤ 7 (não pode passar do número de equações). Logo **dim S ≥ 5**; o mínimo 5 ocorre quando p = 7.
