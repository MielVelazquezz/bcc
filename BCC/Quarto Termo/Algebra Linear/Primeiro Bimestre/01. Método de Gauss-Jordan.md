Método de Gauss-Jordan é a união dos nomes de dois matemáticos diferentes cujos trabalhos deram origem ao famoso método de eliminação de Gauss-Jordan na matemática.

Seu algoritmo de álgebra linear é usado para resolver [[00. Palavras-Chaves#1. Sistemas Lineares|sistemas de equações lineares]], pois:
- transforma uma matriz numérica em uma forma chamada **matriz escada reduzida por linhas**;
- facilita encontrar diretamente os valores das incógnitas de um sistema.

## Os três casos de sistemas lineares
Por razões didáticas, o estudo dos sistemas de equações lineares é feito separadamente em três casos:
1. sistema de **n** equações lineares com igual nº de variáveis;
2. sistema de **m** equações lineares com **n** variáveis (m ≠ n);
3. sistema de equações lineares **homogêneo** (m = n ou m ≠ n).

O Gauss-Jordan (junto com o [[02. Método da Matriz Inversa|Método da Matriz Inversa]]) resolve o **caso 1**: sistemas quadrados, com o mesmo número de equações e de incógnitas.

---
## Antes de tudo -> Escalonamento (Eliminação de Gauss)
Antes do Gauss-Jordan propriamente dito, existe a etapa-base: **escalonar** o sistema. Escalonar é transformá-lo em outro **sistema equivalente** que tenha uma resolução mais fácil.

### Forma escalonada (forma escada)
Ao escalonar um sistema, uma "escada" vai se formando: de equação para equação, no sentido de cima para baixo, há um aumento dos coeficientes nulos da esquerda para a direita.

Formalmente: uma matriz está na **forma escalonada** (ou forma escada) quando o número de zeros à esquerda do primeiro elemento não nulo de cada linha **aumenta** a cada linha.

### Linha pivô e elemento pivô
O escalonamento é feito em etapas, escolhendo as linhas de cima para baixo:

- na 1ª etapa, escolhe-se a **linha 1**; na 2ª etapa, a **linha 2**; e assim por diante. A linha escolhida em cada etapa é a **linha pivô** (ou linha chave).
- dentro da linha pivô, escolhe-se um elemento especial, o **elemento pivô**:
    - se a linha pivô é a primeira linha, o elemento pivô é, inicialmente, o primeiro elemento dela;
    - para as demais linhas pivô, o elemento pivô fica numa coluna **à direita** do pivô anterior (da linha imediatamente acima).

### Algoritmo (exemplo com 3 equações e 3 incógnitas)
1. Monta-se a matriz a partir dos coeficientes e dos termos independentes do sistema.
2. Com a matriz montada, realiza-se uma operação elementar (soma, subtração, multiplicação ou divisão de linhas) que anule os elementos **abaixo** do pivô — por exemplo, subtrair a linha 2 pela linha 1 para zerar o primeiro elemento da linha 2, depois subtrair a linha 3 por um múltiplo adequado da linha 1 para zerar o primeiro elemento da linha 3.
3. Repete-se o processo para os pivôs seguintes (ex.: somar/subtrair a linha 3 com a linha 2 para zerar mais um elemento), até restar a forma escalonada.
4. Chegando à forma escalonada, já é possível encontrar os valores das variáveis por **substituição reversa** (de baixo para cima): a última linha já dá o valor de uma variável diretamente, que é substituído nas equações anteriores para achar as demais.

> [!note] Conexão É sobre esta mesma matriz escalonada que se calcula o [[00. Palavras-Chaves#4. Posto (Rank) de uma Matriz|posto]] (nº de linhas não nulas) e se aplica o [[00. Palavras-Chaves#Teorema de Rouché-Capelli|Teorema de Rouché-Capelli]] para classificar o sistema em SPD, SPI ou SI.

## Início Definitivo -> Método de Gauss-Jordan
O Gauss-Jordan é uma variante do escalonamento acima, em que são eliminados **todos** os elementos acima _e_ abaixo do pivô — não só os de baixo. O resultado é uma **matriz identidade**, e a solução sai pronta sem precisar de substituição reversa.

O processo consiste em, após obtida a matriz escada (Parte 1), prosseguir com mais algumas operações elementares sobre linhas, de forma a obter uma matriz mais simplificada: a matriz identidade, também chamada **matriz escada linha-reduzida**.

### O que é a matriz escada linha-reduzida
Por definição, uma matriz R é escada linha-reduzida se:
1. é uma matriz escada;
2. o primeiro elemento não nulo de cada linha não nula (o **pivô**) é 1;
3. na coluna onde ocorre o primeiro elemento não nulo de alguma linha, todos os outros elementos (**mesmo os acima**) são nulos.

> [!note] Conexão com Matrizes Isso é literalmente pegar a definição de [[00. Palavras-Chaves#2. Matrizes|matriz]] como "tabela de números" e aplicar operações sobre linhas até sobrar só a informação essencial — daí o nome "linha-reduzida".

### Algoritmo
Para obter a matriz escada linha-reduzida:
1. Coloca-se, ao lado da matriz dos coeficientes das variáveis (separada por um traço vertical), a matriz-coluna dos termos independentes.
2. Transforma-se, por meio de operações adequadas, a matriz dos coeficientes das variáveis na matriz identidade, aplicando-se simultaneamente à matriz-coluna as mesmas operações.
3. Transformada a matriz dos coeficientes na matriz identidade, a matriz dos termos independentes fica transformada, ao final, na **solução do sistema**.

Detalhando o passo 2 (como chegar à matriz identidade a partir da matriz escada):
1. Transforma-se todos os pivôs em 1, multiplicando as linhas não nulas i ∈ {1, 2, ..., r} pelos multiplicadores 1/pivô.
2. Começa-se pelo **último** pivô, anulando todos os elementos **acima** dele, e prossegue-se até o segundo pivô (inclusive). Como acima do primeiro pivô não há elementos, o processo se completa.

> [!tip] Diferença para o Gauss comum (Parte 1) No escalonamento simples, para-se na matriz escada e resolve-se por substituição "de baixo para cima". No Gauss-Jordan, continua-se zerando também acima dos pivôs até não sobrar nada para substituir — a resposta já sai pronta na coluna dos termos independentes.

### Conexão com Posto (Rank) e o Teorema de Rouché-Capelli
O [[00. Palavras-Chaves#4. Posto (Rank) de uma Matriz|posto]] da matriz aparece naturalmente durante o escalonamento, e é exatamente o que o **Teorema de Rouché-Capelli** formaliza (p = posto da matriz ampliada, q = posto da matriz de coeficientes, n = nº de variáveis):
- **p > q** → sistema **impossível** (SI) — aparece uma linha do tipo `0 0 0 | k`, com k ≠ 0;
- **p = q = n** → sistema **possível e determinado** (SPD) — solução única (o caso que o Gauss-Jordan resolve diretamente, terminando na matriz identidade);
- **p = q < n** → sistema **possível e indeterminado** (SPI) — infinitas soluções, com grau de liberdade **G = n − p**.

No caso SPI, o Gauss-Jordan ainda funciona, só que o resultado final não é mais a matriz identidade: sobram colunas sem pivô, que correspondem às **variáveis livres**. As demais (**variáveis amarradas**) ficam expressas em função delas. Detalhes em [[00. Palavras-Chaves#Grau de liberdade, variáveis livres e amarradas]].

### Conexão com Inversão de Matrizes
Para matrizes 3×3 ou maiores, a forma mais usada de obter a matriz inversa (A⁻¹) é aplicar essa mesma lógica de escalonamento à matriz aumentada [A | I] até ela virar [I | A⁻¹]. Ou seja, o Gauss-Jordan é a base técnica também do [[02. Método da Matriz Inversa]] — a diferença está no que se decide calcular ao final (a solução do sistema vs. a matriz inversa reutilizável).
