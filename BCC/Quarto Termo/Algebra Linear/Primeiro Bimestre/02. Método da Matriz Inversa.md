Assim como o [[01. Método de Gauss-Jordan|Gauss-Jordan]], este método resolve sistemas de **n equações lineares com n variáveis** (sistemas quadrados). A diferença é o que ele calcula: em vez de chegar direto na solução do sistema, ele calcula a matriz inversa A⁻¹ e, a partir dela, obtém a solução.

---
### A ideia
Um sistema linear quadrado pode ser escrito na forma matricial:
```
A · x = b
```

onde A é a matriz dos coeficientes, x é o vetor das incógnitas e b é o vetor dos termos independentes. Se A é invertível, basta multiplicar os dois lados por A⁻¹:
```
x = A⁻¹ · b
```

> [!note] Essa é a aplicação direta do conceito de [[00. Palavras-Chaves#3. Inversão de Matrizes|Inversão de Matrizes]]: a matriz inversa "desfaz" a transformação de A, isolando o vetor x — o equivalente a "dividir por A", que não existe diretamente entre matrizes.

---
### Como obter a matriz inversa
**Caso 2×2:** existe uma fórmula pronta.

Para uma matriz `A = [[a, b], [c, d]]`, a inversa é:
```
A⁻¹ = 1/(ad - bc) · [[d, -b], [-c, a]]
```

Os elementos das diagonais principais trocam de lugar, e os elementos da diagonal secundária trocam de sinal, mantendo a posição. Essa fórmula pode ser obtida facilmente a partir da matriz dos cofatores.

**Caso 3×3 ou maior:** não há fórmula direta prática — o **escalonamento** é uma das técnicas mais importantes para inverter matrizes nesse caso.

> [!note] Esse escalonamento é exatamente o algoritmo do [[01. Método de Gauss-Jordan]], só que aplicado de outra forma: em vez de escalonar [A | b], escalona-se a matriz aumentada **[A | I]** (A ao lado da matriz identidade) até que o lado esquerdo vire a identidade. Nesse ponto, o lado direito terá se transformado em **A⁻¹**.
> 
> Ou seja, os dois métodos usam a mesma ferramenta (eliminação de Gauss-Jordan); a diferença é só o que se coloca do lado direito da barra vertical — o vetor de termos independentes (Gauss-Jordan "puro") ou a matriz identidade (Método da Matriz Inversa).

### Quando usar cada método

|                  | Gauss-Jordan Direto                 | Método da Matriz Inversa                                                      |
| ---------------- | ----------------------------------- | ----------------------------------------------------------------------------- |
| Quando usar      | resolver **um** sistema específico  | resolver o **mesmo sistema A·x = b** várias vezes, com b diferente a cada vez |
| O que se calcula | a solução (x₁, x₂, ...) diretamente | A⁻¹, reaproveitável para qualquer vetor b                                     |
| Vantagem         | menos contas para um único caso     | calcula A⁻¹ uma vez só e reaproveita                                          |

> [!note] É o mesmo raciocínio do exemplo de [[00. Palavras-Chaves#3. Inversão de Matrizes|criptografia]]: se a mesma matriz A codifica várias mensagens diferentes, vale mais a pena calcular A⁻¹ uma única vez (via escalonamento) do que resolver o sistema do zero para cada mensagem nova.

---
## Pré-requisito: existência da inversa

Só existe A⁻¹ se A for uma matriz **quadrada** e tiver **posto máximo** (posto = número de linhas/colunas). Se, ao escalonar [A | I], surgir uma linha de zeros do lado de A, a matriz não é invertível.

> [!note] Esse é o mesmo critério explicado em [[00. Palavras-Chaves#4. Posto (Rank) de uma Matriz|Posto (Rank) de uma Matriz]]: se o posto de A for menor que sua dimensão, o sistema associado não tem solução única — e, por consequência, A não tem inversa.
