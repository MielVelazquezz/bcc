É um sistema de equações lineares onde todos os termos independentes são iguais a zero — a matriz dos termos independentes B é a matriz nula.
```
A · X = 0
```

onde m = número de equações e n = número de incógnitas (variáveis).
## Sempre tem solução
Um sistema homogêneo é **sempre possível**, já que admite a **solução trivial**:

```
S = {(0, 0, ..., 0)}
```

Substituindo todas as variáveis por zero, todas as equações são satisfeitas — por isso nunca cai no caso impossível.

> [!note] Conexão com Rouché-Capelli Isso é um caso particular do [[00. Palavras-Chaves#Teorema de Rouché-Capelli|Teorema de Rouché-Capelli]]: como B = 0, a matriz ampliada [A | 0] sempre tem o mesmo posto que A (acrescentar uma coluna de zeros nunca aumenta o posto). Logo **p = q** sempre — nunca ocorre p > q (sistema impossível) num sistema homogêneo.

## Determinado × Indeterminado
Mesmo sendo sempre possível, o sistema homogêneo ainda pode ser **determinado** ou **indeterminado**:

- **Possível e determinado (SPD):** a única solução é a trivial (0, 0, ..., 0). Ocorre quando p = q = n.
- **Possível e indeterminado (SPI):** além da trivial, existem outras soluções (infinitas). Ocorre quando p = q < n.

> [!note] Conexão com Posto e Gauss-Jordan A classificação segue exatamente a mesma lógica do [[01. Método de Gauss-Jordan#Conexão com Posto (Rank) e o Teorema de Rouché-Capelli|Gauss-Jordan]]: escalona-se A, conta-se o posto (p = q, pois B = 0) e compara-se com n. Se sobrarem colunas sem pivô, essas viram variáveis livres e o sistema tem infinitas soluções além da trivial — mesmo raciocínio de [[00. Palavras-Chaves#Grau de liberdade, variáveis livres e amarradas|grau de liberdade]].
